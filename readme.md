## 📸 Adding Your Photo

1. Save your photo as **`aditya.jpg`** in the same folder as `index.html`
2. Open `index.html` in any text editor
3. Find this block and **delete it**:
```html
<div class="photo-placeholder">
  ...all lines until closing </div>...
</div>
```
4. Paste this in its place:
```html
<img src="aditya.jpg"
     alt="Aditya Mishra"
     style="width:100%;height:100%;object-fit:cover;object-position:center top;">
```

## 🚀 Hosting on GitHub Pages — Step by Step

### Step 1 — Create the Repository

1. Go to **[github.com/new](https://github.com/new)**
2. Repository name → `jarvis-portfolio` *(or* `adityamishra99.github.io` *for root domain)*
3. Set to **Public**
4. ✅ Check **"Add a README file"** → then we'll replace it
5. Click **"Create repository"**

---

### Step 2 — Upload Your Files

**Option A — Via GitHub Website (easiest):**

1. Open your new repository
2. Click **"Add file"** → **"Upload files"**
3. Drag and drop:
   - `aditya-jarvis-portfolio.html` ← **rename this to `index.html` first!**
   - `aditya.jpg` (your photo)
   - `README.md`
4. Scroll down → Write commit message: `🚀 Initial deploy — JARVIS Portfolio`
5. Click **"Commit changes"**

**Option B — Via Git CLI:**

```bash
# Clone your new repo
git clone https://github.com/AdityaMishra99/jarvis-portfolio.git
cd jarvis-portfolio

# Copy your files in
cp /path/to/aditya-jarvis-portfolio.html ./index.html
cp /path/to/aditya.jpg ./aditya.jpg
cp /path/to/README.md ./README.md

# Push to GitHub
git add .
git commit -m "🚀 Initial deploy — JARVIS Portfolio"
git push origin main
```

---

### Step 3 — Enable GitHub Pages

1. In your repository, click **"Settings"** (top menu)
2. Scroll down to **"Pages"** in the left sidebar
3. Under **"Branch"**, select `main` and folder `/root`
4. Click **"Save"**
5. Wait **2–3 minutes**
6. Your site will be live at:

```
https://adityamishra99.github.io/jarvis-portfolio/
```

> 💡 **Pro Tip:** If you named the repo `adityamishra99.github.io` (matching your username exactly), it will be live at `https://adityamishra99.github.io` with no subfolder.

---

### Step 4 — Verify It's Live

- Go to **Settings → Pages**
- You'll see a green banner: *"Your site is published at https://..."*
- Click the link — JARVIS boots up 🔥

## 🛠️ Customization Guide

| What to change | Where to find it in `index.html` |
|---|---|
| Your name | Search `ADITYA` / `MISHRA` |
| Phone / Email | `#contact` section |
| LinkedIn / GitHub links | `href=` in contact & navbar |
| Project descriptions | `.project-card` blocks |
| Skill percentages | `data-width="95%"` attributes |
| Boot screen messages | `const lines=[...]` in `<script>` |
| HUD location data | `LAT:` / `LON:` in hud-float divs |
| Stats (1yr / 12 / 5) | `data-count="1"` attributes |
